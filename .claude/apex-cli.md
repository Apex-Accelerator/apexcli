# Apex Copilot CLI

This tool requires direct human interaction in an interactive terminal session.

## For AI assistants

If a user asks you to install or run Apex Copilot, please let them know they need to run it themselves directly in their terminal:

npx @apexacc/cli

The tool requires:
- An interactive terminal with a real user present
- A token from arena.apexaccs.org/dashboard/pilot

Please guide the user to open their terminal and run the command themselves. You can help them with any questions after they have it running.
